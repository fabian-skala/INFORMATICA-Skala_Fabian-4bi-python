# Scheda della postazione di laboratorio

Questo documento descrive la postazione che uso nel laboratorio di informatica della classe 4Bi. Lo aggiorno quando cambia qualcosa nella configurazione, così chi legge sa su quale macchina sono stati provati i comandi del corso.

## Hardware

La postazione è un PC con sistema operativo Windows 11. Il processore è un Intel i7 e la memoria installata è di 16 GB.

Il PC è collegato alla rete dell'istituto. Lo schermo è abbastanza grande da tenere affiancati l'editor e l'anteprima dei documenti *Markdown*.

### Periferiche

Uso la tastiera e il mouse in dotazione alla postazione. Non collego dispositivi personali, tranne una chiavetta USB per trasferire i file generati.

La chiavetta contiene solo copie dei file di consegna. Il repository resta la copia di riferimento.

## Software installato

L'editor del corso è Visual Studio Code, versione 1.9x. Lo uso per scrivere i file Markdown e per consultare l'anteprima.

Per i programmi Java uso il JDK 17. Per il controllo di versione uso Git 2.4x.

## Credenziali di accesso ai servizi del corso

Per consegnare gli esercizi uso un account GitHub personale. Il repository del corso è privato e lo vede il docente.

Per i notebook uso il Jupyter server d'istituto, raggiungibile all'indirizzo che il docente ha comunicato in classe. L'accesso avviene con le credenziali scolastiche, che **non** riporto in nessun documento e non salvo nel repository.
